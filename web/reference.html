Unsupported / Blocked Constructs

Blocked
Module / ConstructStatusReason
re.stereo_freeverb, re.mono_freeverb, re.zita_rev1_stereo, re.jpverb, re.satrev, re.kb_rom_rev1Hard LimitExceeds `188 B` `instance[2]` / `529,200 B` SDRAM caps or uses static globals. Use re.dattorro_rev, re.jcrev, or zm_freeverb.
hbargraph(...), vbargraph(...)BlockedZoom MS Plus hardware has no output meter/bargraph channel. Caught transitively via `faust -e`.
co.RMS_FBFFcompressor_N_chan / meter-taking co.*UnsupportedRequires `hbargraph` meter output or invalid signature.
ffunction, fvariable, fconstantBlockedUser DSPs cannot inject raw C FFI; non-`<math.h>`/`<stdlib.h>` FFI is rejected transitively.
import("...") other than stdfaust.lib / zoom.libBlockedArbitrary external libraries are disallowed.
pm.* (physmodels.lib)BlockedPhysical-modeling instrument waveguides/tables (pm.guitar_ui_MIDI, pm.marimba fail cl6x), not stereo audio-in pedal effects.
ho.* (hoa.lib)BlockedHigh-order Ambisonics (2*N+1 surround buses) for multi-speaker spatial arrays; Zoom MS Plus is strictly stereo I/O.
sy.* (synths.lib)BlockedGate/pitch-driven synth & drum generators (kick, clap, dubDub), not audio-in effects (standalone synth voices can be built with os.*, en.*, and fi.*).
dx.* (dx7.lib)BlockedFull 32-algorithm 6-op DX7 FM synthesizer; built for MIDI keyboard synthesis and far too heavy for a pedal slot.
wd.* (wdmodels.lib)BlockedWave Digital Filter circuit trees; anything beyond a tiny stage expands into deeply coupled expressions that blow C674x register limits / cl6x (e.g. ve.klonCentaur fails cl6x).
wa.* (webaudio.lib)BlockedW3C Web Audio BiquadFilterNode compatibility port; redundant on hardware since fi.* (filters.lib) already covers all standard biquad/SVF/EQ needs.
ve.klonCentaur (and untested ve.*)BlockedFails `cl6x` (uses `wd.*` Wave Digital Filters). Use `ve.moog_vcf`, `ve.korg35LPF`, `ve.crybaby`, etc.
ef.echo2s .. ef.echo43sHard LimitExceeds `529,200 B` SDRAM cap (use `ef.echo(0.5, ...)` or `zm_delay`).
Non-power-of-two de.delay(N, ...)UnsafeEmits integer `%` (`CALLP __c6xabi_remi`), rejected by `REPORT.md`.
State > 188 B (`instance[2]`) or SDRAM > 529,200 B (`instance[3]`)Hard LimitRejected by `c_backend.py` / `emitter.py`.
Heavy chained filters/delays spilling B14Hard LimitExceeding 31 C674x registers causes `cl6x` to use `B14`, rejected by `REPORT.md`.
0 params or > 10 paramsHard LimitCleanroom `.ZD2` scaffold requires 1–10 UI controls (`hslider`, `vslider`, `nentry`, `checkbox`, `button`).
